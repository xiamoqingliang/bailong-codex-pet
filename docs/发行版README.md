# 白龙桌宠 · Codex 完整适配版 v0.5.1.1

基于原作者 **白龙桌宠 v0.5.1**，将完整动画、互动台词与音效接入 Codex Desktop，并提供专属控制栏、跨项目任务卡、同会话聊天和统一的白紫色界面。

这是此前 **v041 完整适配版**的后续版本。适配版号为 **v0.5.1.1**，原作者引擎版本仍为 **v0.5.1**。

## 安装与使用

1. 安装并登录自己的 Codex 桌面应用，确认其可以正常使用。
2. 下载 `Bailong-Codex-v051-0.5.1.1-windows-x64.zip`，完整解压到位置固定、当前用户可写的目录。
3. 双击 **一键安装到Codex.cmd**，等待安装完成。包内已包含 Python、解码器和动画资源，无需另外配置运行环境。
4. 首次显示会预加载动画，需要等待片刻。若 Mini 列表尚未更新，在 Codex 的“设置 → Mini 与虚拟宠物”中点击“刷新”，选择 **白龙完整版**并允许显示。

日常使用请通过上述安装入口启用完整联动。`data/BailongPet.exe` 保留原作者独立程序，直接运行它不会启用本适配版的完整控制栏与联动。

```text
Bailong-Codex-v051/
├─ 一键安装到Codex.cmd
├─ 一键卸载白龙.cmd
├─ README.md
└─ data/                  必要程序、运行库、动画、音效及许可
```

请保留整个解压目录，不要只复制 EXE，也不要拆散 `data` 文件夹。

## 主要功能与操作

### 控制栏

**白龙｜聊天｜额度｜动作｜设置｜−**

- **白龙**：保留标题，拖动标题或角色本体可移动桌宠。
- **聊天**：打开聊天小窗；在其中选择任务文件夹、新建对话或打开历史。支持 `Ctrl+Enter` 发送。
- **额度**：主动查询 Codex 相关额度，同时保留白龙的查询台词。
- **动作**：手动选择互动、工作、待机与移动动作。
- **设置**：管理大小、自移动、固定桌宠、全屏隐藏、任务提醒与音效；再次点击“设置”或点击“完成”均可保存并关闭。
- **−**：隐藏桌宠；可从 Codex 的显示入口或白龙托盘恢复。

吸边时控制栏和任务卡默认收起，鼠标进入白龙范围后浮现；移到控件上可继续操作，离开后淡出。

### 固定桌宠

“固定桌宠”默认关闭，与“自动移动”分开控制。开启后，自发触发移动动作只播放动画，实际位置保持不变；用户拖拽白龙或控制栏、手动选择移动动作时，仍可改变位置。设置会保存，下次启动继续使用。

### 消息与窗口

- **互动消息框**：用于点击互动和额度查询台词，固定尺寸；短文字居中，长文字在框内滚动。优先贴在白龙上方，空间不足时放到下方。
- **任务消息提示**：用于任务进展与完成结果，显示在白龙左右两侧。
- **额度面板**：查询中、结果和失败状态均在左右侧显示；成功结果显示约 12 秒后收起，连接超时先显示失败提示再收起。
- **设置面板**：固定为 350×460 逻辑像素，完整显示当前选项，不因侧边空间不足而缩小；保持左右居中并避开控制栏和任务卡。
- **层级与互斥**：白龙本体优先，其次为控制栏和任务卡。设置打开时关闭其他受约束展开层；用户主动打开其他窗口会先保存关闭设置。历史与互动消息框独立。
- **换边动效**：先收回白龙身后，再从新方向展开；同侧拖动即时跟随，连续拖动不反复重启动效。

### 聊天与历史

桌宠提交的内容交由 Codex Desktop 的同一会话执行，回复返回白龙；原生 Codex 中后续追加的对话也会同步。历史中的命令或文件编辑记录供只读查看，点击详情不会再次执行操作。

公开思考摘要、命令和文件详情默认收起。命令内容采用简化展示；文件修改按“原文件／新文件”对照，完整展示变化段，新增文件显示全部内容。只有文件代码区不自动换行并提供横向滚动，普通聊天继续自动换行。

每次打开历史默认定位最新内容；展开详情时保持阅读位置。已删除或归档的 Codex 会话从同步列表隐藏，本地缓存保留备份。

## 从旧版升级

1. 将新安装包完整解压到新的固定目录，无需覆盖正在运行的旧目录。
2. 运行新目录中的 **一键安装到Codex.cmd**。
3. 若旧版仍在运行，安装器等待正常关闭 Codex 后再接管，不强制中断当前会话。
4. 下次打开 Codex，选择“白龙完整版”并允许显示。

同一时间只运行一个完整版。升级保留聊天记录；本版使用独立的 `DesktopPet-v051` 设置空间，不承诺逐项继承旧版布局和偏好。移动安装目录后，请在新位置重新运行安装入口，更新启动路径。

## 卸载

双击安装包顶层的 **一键卸载白龙.cmd**，等待结束后再删除或移走解压目录。

卸载会按安装归属停止自己的助手、清理对应自启动与匹配的本地入口，并在适用时还原相关选择；保留聊天历史、项目文件、其他桌宠和用户后续修改的设置。已被修改或仍由其他安装使用的文件会按保护规则保留。

已迁移到云端的同名条目不通过本地卸载强制删除，可在 Codex 的宠物管理界面自行处理。

## 兼容性、数据与验证

- 面向 Windows 10/11 x64；当前版本在本机 Windows 环境完成验证，其他系统及 Windows ARM 未验证。
- 完整联动面向本机 Codex Desktop 和默认用户配置目录。聊天和额度查询需要自己的 Codex 安装、登录与网络；不会同步普通 ChatGPT 网页聊天列表。
- 任务状态与历史读取基于本地可用记录；远程任务或未暴露的原生状态不保证覆盖。Codex 更新后，本地接口或数据库结构变化可能需要进一步适配。
- 状态轮询和历史读取不额外发起模型任务；用户从桌宠提交聊天或任务会正常使用自己的 Codex 额度。
- 发布包不包含账号、登录凭证、聊天记录、个人布局或运行日志。
- 当前已通过 **412 项联动与 UI 检查、52 项安装器检查、13 项 PowerShell 卸载用例**，以及隔离安装／重复安装／卸载／重装流程；包内环境验证全部 **35 段／4426 帧**正常加载，并完成逐文件校验。
